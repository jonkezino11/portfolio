# Jonathan Pandji Portfolio Website

## Files
- index.html — homepage
- boat.html — V-hull boat case study
- plant-watering.html — plant-watering case study
- styles.css — site styling
- assets/ — place your images and resume PDF here

## Run locally
Double-click index.html, or open the folder in VS Code and use Live Server.

## Add images
Replace a placeholder like:

<div class="image-placeholder">Add image</div>

with:

<img src="assets/boat-final.jpg" alt="Final autonomous V-hull boat prototype">

## Resume
Place your resume at:
assets/Jonathan_Pandji_Resume.pdf

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload these files.
3. Open Settings → Pages.
4. Choose the main branch as the deployment source.
5. GitHub will generate a public URL.
