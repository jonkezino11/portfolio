Autonomous Plant Watering System

Product design, embedded programming, and sensor-based automation for autonomous plant care.

SolidWorksESP32SensorsC++
Add completed plant-watering system photo

Overview

The project goal was to develop a system that continuously monitors soil moisture and automatically waters a plant when moisture falls below a target threshold.

My contributions included SolidWorks enclosure design, ESP32 programming, hardware integration, sensor calibration, and troubleshooting.

Mechanical Design

Add SolidWorks enclosure model

I designed the enclosure to support sensor placement, protect electronic components, provide practical access to hardware, and organize wiring within a compact form.

Automation Logic

Soil Moisture Sensor → ESP32 → Threshold Check → Watering Activation

The ESP32 was programmed in C++ to read real-time soil moisture data and trigger watering based on the measured condition.

Testing

  • Sensor calibration
  • Hardware integration
  • Circuit troubleshooting
  • System testing
  • Performance refinement

Outcome

The completed system demonstrated how mechanical design, sensing, embedded programming, and automation can be integrated into a simple autonomous product.
